01

Recruitment Funnel & Hiring Process Optimization

End-to-end analysis of 34,673 job applications and 52K hiring-stage events across 420 openings (synthetic ATS data). SQL, Python and a logistic-regression model show where the funnel leaks: the onsite interview is the bottleneck (31% of process time), candidates who wait 3+ weeks are 3.4× more likely to withdraw, and pay below expectations drives half of all offer declines. Referrals convert best, while agencies cost 8× more per hire. A what-if simulation estimates ~20 extra hires a year from a 5-day faster onsite stage.

Tools : Excel, SQL, Python (pandas, scikit-learn), Power BI
Analysis : Funnel Conversion, Bottleneck Analysis, Source ROI, Offer-Acceptance Model
Presentation Report GitHub Repo
02

Monthly Revenue Forecasting & Budget Variance Analysis

FP&A project on real Walmart sales data (421K weekly records, 45 stores, $6.7B). Weekly sales are allocated to calendar months in SQL, a budget is built from growth targets and compared with actuals, and five forecasting models are backtested. Year to date the business is +0.59% ahead of budget, but 90% of February's beat was the leap day. Holt-Winters (1.3% MAPE) puts the full year within −0.2% to +0.6% of budget, with the risk concentrated in October–November and three large stores.

Tools : SQL, Python (statsmodels), Excel, Power BI
Analysis : Budget vs Actual, Variance Drivers, Holt-Winters Forecast, Backtesting
Presentation Report GitHub Repo
03

Credit Risk & Loan Portfolio Analysis

Risk analysis of 42,535 real LendingClub loans ($460M lent). SQL and Python measure default and delinquency by borrower segment, loan type, grade and state, and a default-risk model (ROC-AUC 0.71) ranks borrowers better than the lender's own grade. Up to $20.4M (19.5%) of the outstanding book is at risk, and three simple approval rules would have avoided 43% of defaults while lifting the net return from 7.2% to 9.3%.

Tools : SQL, Python (scikit-learn), Excel, Power BI
Analysis : Default Rates, Risk Segmentation, Pricing vs Losses, Policy Simulation
Presentation Report GitHub Repo
